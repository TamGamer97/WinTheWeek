# WinTheWeek — Website v2

A standalone, responsive landing page. Open `index.html` for the landing page or serve this directory to also use the exported app in `app/`.

Includes local fonts, light/dark themes, a clickable routine preview, animated progress, scroll reveals, and reduced-motion support. No added dependencies. The preview is illustrative; it does not change app data.

The local preview server maps the Expo export's root asset URLs to `app/` and can be started with `node server.cjs`. Open http://localhost:4173.
