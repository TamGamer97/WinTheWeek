# Icon refinement

The selected direction preserves the original interwoven W, diagonal cuts and tall yellow rising stroke. Only its overall scale, placement and palette are refined.

- `icon-original-mark-refined.png`: current refined design, 1254 × 1254 PNG, generated with the built-in image editing tool from the original appstore.png. This is design artwork, not a platform-sized icon pack.
- `preview.html`: original/refined comparison at 48 and 64 CSS pixels, with rounded-square and circular masks on light and dark backgrounds.
- `original.png`: unchanged copy of the original for comparison.
- `icon-cobalt.png`: earlier simplified concept, rejected; not the current direction.
- `prompt.txt`: exact image-editing brief for the current design.

Target palette: dark ink navy #152D4B, warm white #F6F4EE, softer golden yellow #F3CA58. These are prompt targets rather than guaranteed uniform sampled colours in the generated image.

The existing app assets and app.json are unchanged. Platform exports and Android foreground/background separation are still needed before installation. Browser masks are visual references, not a device verification.
